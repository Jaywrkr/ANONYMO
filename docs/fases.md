# Fases

| Fase | Rama | Qué sale |
|---|---|---|
| 0 | `fase-0/base` | Estructura: Next.js, Tailwind, fuentes locales, paquete del equipo |
| 1 | `fase-1/direccion-arte` | Dirección de arte desde MyMind: color, tipografía, movimiento; agentes como esferas de degradado; pantallas de inicio, sala y ficha |
| 2 | `fase-2/blobs-3d` | Los 22 agentes en 3D con su objeto, interacción y rendimiento en celular |
| 3 | `fase-3/web-cliente` | Web completa: inicio, cómo trabajamos, agentes, casos, contacto |
| 4 | `fase-4/jurado` | Revisión tipo Awwwards (diseño, usabilidad, creatividad, contenido) + velocidad y accesibilidad; ciclo de mejora |
| 5 | `fase-5/pipeline` | Prototipo: pedido → Atlas arma el plan → los agentes trabajan y entregan |
| 6 | `fase-6/estudio` | Panel interno: crear proyecto, ver agentes, aprobar pasos |
| 7 | `fase-7/conexion` | La sala de la web muestra el avance real del pipeline |
